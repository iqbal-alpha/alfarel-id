# Workspace Configuration & Guidelines

This project is configured with two core frameworks:
1. **Superpowers** (`.agents/plugins/superpowers`): Engineering methodology enforcing planning, TDD, systematic debugging, and rigorous verification.
2. **Taste Skill** (`.agents/plugins/taste-skill`): Frontend design framework delivering premium, tailored, anti-slop user interfaces.

## Engineering Workflow (Superpowers)
- **Before coding**: Check if a skill applies. Use `brainstorming` before designing solutions, and `writing-plans` to break down multi-step work.
- **During coding**: Follow `test-driven-development` and maintain task tracking using artifacts.
- **Debugging**: Use `systematic-debugging` to isolate root causes before proposing patches.
- **Before completion**: Run `verification-before-completion`.

## UI & Frontend Standards (Taste Skill)
- **Design Read**: State a one-line Design Read before coding any frontend interface.
- **Anti-Slop**: Avoid generic LLM design defaults (AI-purple gradients, generic glassmorphism, boring uniform grids).
- **Aesthetics**: Leverage available skills (`minimalist-skill`, `brutalist-skill`, `soft-skill`, `brandkit`) to create distinct, high-end interfaces fitting the Apparel brand.
